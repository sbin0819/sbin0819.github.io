Peach Peach Diary

A roguelike deck-building game, one floor at a time

About

Peach Peach Diary is a single-player roguelike deck-builder. Collect cards, shape your deck, and pick your path through branching floors of battles and events. Every run offers a different route, a different deck, and different artifacts.

Game Modes

Normal A standard run with the default rules
Challenge A harder run with special rules
Custom Configure your own rule set

Features

  • Procedurally generated floors with branching routes
  • A different build every run through cards and artifacts
  • No ads, fully offline play
  • Seven languages — English, Korean, Japanese, Simplified Chinese, Spanish, French, and Italian
