Questions fréquentes

Ma progression a disparu.

La progression est enregistrée uniquement sur votre appareil. Désinstaller l'application supprime également les parties sauvegardées.

Quelle est la différence entre les modes de jeu ?

Le mode Normal applique les règles par défaut. Le mode Défi propose une partie plus difficile avec des règles spéciales. Le mode Personnalisé vous permet de configurer vos propres règles avant de commencer.

Comment changer la langue ?

Utilisez l'option Langue dans le menu des réglages. Le français, l'anglais, le coréen, le japonais, le chinois simplifié, l'espagnol et l'italien sont pris en charge.

Une connexion internet est-elle nécessaire ?

Non. Peach Peach Diary fonctionne entièrement hors ligne, sans publicité ni inscription.

Signaler un bug

Si vous avez trouvé un bug, ces informations nous aident à le corriger beaucoup plus vite :

  • Le modèle de votre appareil et la version du système
  • Où cela s'est produit : quel mode, quel étage ou quel combat
  • Une capture d'écran, si possible
