Frequently Asked Questions

My progress is gone.

Progress is stored only on your device. Deleting the app also deletes your saved runs.

What is the difference between the game modes?

Normal Game uses the default rules. Challenge Mode is a harder run with special rules applied. Custom lets you configure your own rule set before starting a run.

How do I change the language?

Use the Language option in the Settings menu. English, Korean, Japanese, Simplified Chinese, Spanish, French, and Italian are supported.

Do I need an internet connection?

No. Peach Peach Diary works fully offline, with no ads and no sign-up.

Bug Reports

If you found a bug, including the details below helps us fix it much faster:

  • Your device model and OS version
  • Where it happened — which mode, floor, or battle
  • A screenshot, if possible
